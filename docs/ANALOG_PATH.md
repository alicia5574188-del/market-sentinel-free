# V10 历史途中方向交易：当前实际规则

用户最新要求优先：历史相似K线整体上涨或下跌直接决定方向，不再叠加均线/缩量/回踩恢复入场策略。沿用GitHub、Cloudflare、Durable Object、D1和模拟账本。新版本仅模拟验证，不自动启用实盘。

## 开仓：方向 → 路径 → 当前价或等待价

1. 固定六币BTC/ETH/SOL/BNB/XRP/DOGE，每分钟刷新报价与调度；每五分钟更新完整K线和历史匹配。关闭页面仍运行。最新两小时对照已存历史，推演后一小时；时间段、星期/周末、波幅、斜率、量能和已有事件资料参与匹配。历史不断限速向前回补，本地近期加轮换旧日期参与检索。事件覆盖不完整，不虚构消息。
2. 至少5段互不重叠且未来路径已完整发生的历史样本、有效样本至少4.5。完整历史预测不超过一个五分钟周期。每段按先触及向上/向下的可交易波动投票（幅度为估计往返成本1.5倍、至少0.05%）；超过半数全部独立片段先走同一方向，确定多空。同根K线双向触及且无法判断先后者弃权，不要求终点或中位数同向。分散/不足/过期就不造方向，也不偷偷切换别的策略。
3. 重放所有相似样本后续12根K线的开高低收，不只统计一小时终点。用目标首次触及前的历史不利波动八成分位减去等待距离，再加当前0.25平均波幅作初始止损距离；至少0.65平均波幅，最大价格2%。更远止损由同一亏损预算换算为更小仓位；开仓后绝不放宽。
4. 只比较两个固定方案：当前参考价格入场；先反向走历史不利波动平均值的一半再入场。目标为历史有利波动平均值的50%加等待距离；不得为通过门槛随意延伸。历史重放采用同根止损优先；等待价格首次在一根K线内触及，不能同时声称获得该根更早出现的止盈。未触及的等待样本不算成交。
5. 每个方案须目标空间至少1.5倍往返估计成本、已成交历史样本含费平均结果不少于0.05风险倍数、目标命中多于净亏结束（含亏损早退），扣费保本/盈利保护另计，不当作亏损止损、历史等待成交覆盖至少40%。默认立即入场；只有等待方案成交覆盖至少60%、估计改善超过0.1风险倍数且立即方案净亏结束至少25%，或立即方案本身不合格，才选择等价。并非全市场优化或已校准胜率。
6. 等待价格及保护/目标一经创建最多冻结15分钟，不随每次报价移动。新历史方向不明或反向取消旧等待计划；过期重新判断。下单前用新报价核验入场区、费用和剩余净优势。同币不重复持仓、同预测计划去重，平仓后冷却5分钟并要求新的计划。

## 退出与资金

持仓不超过60分钟，等待后按原一小时预测剩余时间缩短。计划内逆向波动不因一根小阴线退出；15分钟后仍无0.25初始风险推进且完整K线及当前价都偏离入场超过半个初始止损距离，可提前退出。真实保护价/目标触发优先；利润达到成本1.5倍与价格风险0.5倍中的较大者后，保护到含费保本。绝不因亏损放宽保护或自动翻向。

费用取用户配置与12基点（0.12%往返）较大者，为估计不是已核实费率。历史路径统计扣除此成本，但未来滑点和费用仍可改变收益，不能承诺本金无损。

不再设三笔固定持仓上限。按剩余0.75%权益组合风险除以尚待分配币数、每笔最多0.25%分配；同向高相关或相关未知敞口风险折半。按可用保证金定仓，预留权益5%缓冲。六个独立有效信号可同时分配；资金/风险预算仍会限制敞口，不为满仓放大杠杆。

三连净亏暂停新单30分钟。UTC日初权益1.5%的已实现加完整估计退出成本的浮亏触发持久当日暂停，次日北京时间08:00解除再判断。已有持仓继续管理。
