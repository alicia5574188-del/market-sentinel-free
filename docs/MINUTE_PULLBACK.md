# 一分钟顺势回踩模拟策略 V8

2026-09-05。单一新开仓权威为 `buildScalpCandidate` → `openDirectMarketTrade`。旧策略代码只保留历史复盘所需边界；历史相似模型作为后台辅助，样本不足和分歧不再阻止短线信号。本版本没有实盘资格。

## 运行路径

- 固定 BTC、ETH、SOL、BNB、XRP、DOGE 六币。每分钟共用一次全市场报价，六个一分钟K线请求并发2；启动最多390根，之后每币8根。只使用已完成且连续的行情，本地聚合十五分钟。
- 十五分钟快慢均线同向；一分钟3根受控缩量回踩后，收盘收回前根实体并恢复成交量。目标来自此前真实波段极值，不为达到利润门槛拉远；目标空间至少覆盖3倍预计往返成本。
- 最新报价必须留在信号附近；信号跨一分钟失效。同币已有仓位、五分钟平仓冷却、平仓后未形成新回踩、同一信号重复以及相同相关风险敞口都会阻止重复入场。
- 历史归档仍用原独立 Durable Object。每分钟轮换一个币后台回补及推演，每币约六分钟一次，保留原十分钟回补节流及21,000总写行日预算。归档失败不阻塞新信号和持仓保护。
- 持仓监控独立于扫描，活跃时目标15秒一次。结构复核复用扫描缓存，无第二个一分钟常驻采集器。扫描暂停也不停止旧仓报价保护和十五分钟期限。
- 三分钟无0.25R推进且完成K线与最新价都失去入场确认时退出；达到足以覆盖费用的浮盈后才收紧保护；最长十五分钟，单次全平，不部分止盈、不摊平、不放宽止损。
- 停顿90秒以上的短线仓位按一分钟历史顺序补放。已有止损优先于同根止盈；跳空按可见不利价格结算，不能假装精确成交于旧止损。行情不可用时不能保证止损成交价或精确退出时刻。

## 本金与持久状态

单笔计划风险0.25%权益，含预计往返费用/滑点；合计不超过0.75%，最多3笔用于预留持仓预算。成本取配置与12基点两者较高值，并锁定在订单快照。三连亏暂停30分钟，跨UTC日仍保留未结束的冷却。当日已实现加估计全部平仓成本后的浮动亏损达到日初已结算权益1.5%，持久锁住新开仓到下个UTC日；保护现有仓位继续运行。跨日持仓浮动也计入当日风险，采取保守口径。

每日新增订单最多60笔，是资源安全上限，不是开仓任务。D1入场预留22,000行，应用30,000行预算与账户65,000行运行审计继续保留。当前计划：3笔全天60秒检查点按2倍计费预留8,640行；60单生命周期预留6,000行；30,000预算余15,360行覆盖风险状态、索引、退出、回放与其他必要写入。新增索引支持信号去重、按出场日汇总，日初余额只需每天首次累计，避免每次重读全部历史/500条截断。

升级按最新有效报价归档旧模拟仓位并开启新版本账期；历史库、老订单和通知/账户/紧急控制完整保留。新迁移0026只添加风险日状态和查询索引，再请求原有模拟归档流程。旧实盘仓位不属于本次版本切换。

## 全天预算与恢复验收

`tests/scalp-strategy.test.ts` 用持久存储模拟1440分钟、6币和重复唤醒，验证8,640次行情请求、17,280次缓存意图/结果写入；429退避、重启复用、缺口修复和并发上限都有行为测试。每次扫描分两阶段保存，SQLite DO约5,760运行状态写、2,880闹钟；加持仓闹钟/心跳、归档与辅助更新，应用预计在每日100,000 DO写行以内，给重试和页面查询留余量。D1与DO是分别计量的限额，不能把缓存写误算为零成本。

SQLite DO行计费、闹钟单行、100,000写行/日、13,000 GB-s/日等依据：[Cloudflare 官方价格](https://developers.cloudflare.com/durable-objects/platform/pricing/)。键值合计上限2MB，详见[官方限制](https://developers.cloudflare.com/durable-objects/platform/limits/)。资源估算是本应用上限规划，账户其他应用用量与实际上游延迟仍需要生产审计；不能承诺平台/交易所故障期间绝对无中断。

故障处理：网络7秒超时；逐币指数退避最高10分钟，其余币继续；扫描阶段三次失败熔断5分钟后恢复；持仓监控在外部操作前先预设恢复闹钟，错误后重新安排；原Worker cron和每6小时GitHub审计保留。页面数据失败保留最后有效值并标出过期。发布验收需见扫描时间推进、六币新行情、持仓闹钟推进、正确版本切换和账户D1余量。

验证数据使用确定性场景，不是市场收益回测；不宣称最高胜率、固定开仓频率或已完成真实24小时在线观察。今后小改动优先仅编辑策略/退出纯函数或 `SCALP_POLICY`，运行对应行为测试及必要发布门禁，避免再次重写整条链路。
