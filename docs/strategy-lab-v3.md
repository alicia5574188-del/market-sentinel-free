# 哨兵策略实验室 V3

本文件记录《哨兵量化原件》之后的 V3 多策略升级。原件代码基线保持不变；本升级只在后续 main 上继续演进。

## 目标

解决原件单一综合策略样本积累过慢的问题，但不通过降低原策略门槛来刷订单。

## 实盘边界

- Sentinel Baseline V1 = `contract_v2`，仍是当前 Gate 实盘唯一策略信号来源。
- 新策略统一使用 `shadow_v3:*`，只做影子模拟。
- `live-trading-repository.ts` 的实盘候选仍严格筛选 `simulationModel === "contract_v2"`。
- 新策略达到统计候选线也不会自动接入 Gate，必须以后明确人工批准并单独开发晋级流程。

## V3 四个影子策略

1. 趋势回踩 `trend_pullback`
   - 高周期趋势存在。
   - 5m 回踩 EMA 附近后重新恢复。
   - RSI 不过热、Spot CVD 同向、量能不衰竭。
   - 目的：减少趋势末端追价。

2. 波动收缩突破 `volatility_breakout`
   - ATR/区间先收缩。
   - 完整 5m K 线突破近期高低点。
   - 要求突破量能、Spot CVD、OI 和高周期方向共同确认。
   - 目的：区别真正的压缩突破与普通大阳/大阴线。

3. 震荡均值回归 `range_reversion`
   - 只在低趋势/区间状态启用。
   - 靠近区间边缘并出现 RSI 极值。
   - 要求 Spot CVD 背离或订单簿吸收。
   - 趋势形成时自动失去资格。

4. 相对强弱 `relative_strength`
   - 比较标的 24h 涨跌幅与 BTC/ETH 平均 24h 动量。
   - 自身高周期趋势、Spot CVD、流动性必须同向确认。
   - 标记为实验策略，置信度上限较低，晋级样本要求更高。

## 市场状态路由

V3 将市场分为：
- trend
- range
- compression
- mixed
- stress

高宏观风险、低数据质量或极端资金费率进入 stress，新策略停止开新影子单。

## 影子生命周期真实性

- 只使用已完成 5m K 线。
- 开仓发生在一根 K 线中间时，不使用该根 K 线开仓前已经发生的最高/最低价。
- 免费 Worker 轮转导致某个影子仓位隔几分钟才复核时，会补查上次已覆盖边界之后的全部完整 5m K 线，避免漏掉期间止损/止盈。
- 每个策略/币种有独立活动键和 30 分钟冷却。
- 使用现有逐仓模拟仓位计算、1% 风险预算、手续费和 TP2 净利润可行性检查。

## 晋级候选标准

趋势回踩、突破、震荡策略：
- 至少 50 个完整平仓样本。
- 至少跨 7 个有效交易日。

相对强弱策略：
- 至少 80 个完整平仓样本。
- 至少跨 10 个有效交易日。

共同要求：
- 平均净结果 > 0.08%。
- Profit Factor >= 1.25。
- 最大策略回撤 <= 8%。
- 最大连续亏损 <= 5。
- 最近 20 笔平均净结果 > 0。
- 最近 20 笔 Profit Factor >= 1.10。
- 至少一个该策略真实参与的市场状态中，存在不少于 5 笔且累计正收益的样本簇。

达到以上标准只显示“达到实盘候选线（仍需人工批准）”，绝不自动连接真钱。

## 不以胜率作为唯一目标

策略实验室同时展示：样本数、有效交易日、胜率、平均净结果、Profit Factor、最大回撤、最大连亏、最近 20 笔表现和市场状态表现。

高胜率但盈亏比差的策略不会因为胜率漂亮而自动晋级。

## 后续阶段（有足够样本后再做）

1. 严格 walk-forward / 时间顺序样本外验证。
2. 策略之间的收益相关性与同向暴露统计，避免多个策略实际上押同一个风险因子。
3. 流动性/波动率自适应手续费、滑点和成交冲击模型。
4. 有足够数据后再考虑第二层 meta-label / ensemble，不在小样本阶段训练复杂模型。
5. 清算反转等第五类策略先保留为研究项，不在 V3 初期继续扩张策略数量。

## 版本纪律

`shadow_v3:*` 是本规则集的样本版本。未来如果修改影响入场/退出逻辑的核心规则，应升级 shadow 版本，避免把不同规则产生的历史样本混在一起统计。
