# V13 最相似五段历史途中方向交易：当前实际规则

用户最新要求优先：历史相似K线整体上涨或下跌直接决定方向，不再叠加均线/缩量/回踩恢复入场策略。沿用GitHub、Cloudflare、Durable Object、D1和模拟账本。新版本仅模拟验证，不自动启用实盘。

## 开仓：方向 → 路径 → 当前价或等待价

1. 固定六币BTC/ETH/SOL/BNB/XRP/DOGE，每分钟刷新报价与调度；每五分钟更新完整K线和历史匹配。关闭页面仍运行。最新两小时对照已存历史，推演后一小时；时间段、星期/周末、波幅、斜率、量能和已有事件资料参与匹配。历史不断限速向前回补，本地近期加轮换旧日期参与检索。事件覆盖不完整，不虚构消息。
2. 只取最相似的5段互不重叠且未来路径已完整发生的历史样本，有效样本至少4.5；不足5段就不开仓。完整历史预测不超过一个五分钟周期。每段按先触及向上/向下的可交易波动投票（幅度为估计往返成本1.5倍、至少0.05%）；超过半数五段样本先走同一方向，确定多空。同根K线双向触及且无法判断先后者弃权，不要求终点或中位数同向。分散/不足/过期就不造方向，也不偷偷切换别的策略。
3. 重放所有相似样本后续12根K线的开高低收，不只统计一小时终点。用目标首次触及前的历史不利波动八成分位减去等待距离，再加当前0.25平均波幅作初始止损距离；至少0.65平均波幅且至少2.5倍往返估计成本，最大价格2%。更远止损由同一亏损预算换算为更小仓位，防止过窄止损被普通五分钟波动穿越成数倍风险；开仓后绝不放宽。
4. 只比较两个固定方案：当前参考价格入场；先反向走历史不利波动平均值的一半再入场。目标取多数方向投票片段各自在一小时内最大有利运动的中位数75%，至少覆盖成本，再加等待距离；反向投票片段不再把目标压到手续费下限，也不得为通过门槛随意延伸。历史重放采用同根止损优先；等待价格首次在一根K线内触及，不能同时声称获得该根更早出现的止盈。未触及的等待样本不算成交。
5. 多数片段的首段可交易方向就是入场方向，不再用历史含费期望、目标命中率或净亏片段比例作第二道否决。路径回放仍完整记录这些结果，供后续真实模拟学习。计划只保留可执行边界：扣费后目标至少为止损加费用这一完整风险的0.8倍、等待方案历史成交覆盖至少40%、初始保护距离不超过价格2%。默认立即入场；只有等待方案成交覆盖至少60%、估计改善超过0.1风险倍数且立即方案净亏结束至少25%，才改为等待。并非已校准胜率或盈利保证。
6. 等待价格及保护/目标一经创建最多冻结15分钟，不随每次报价移动。新历史方向不明或反向取消旧等待计划；过期重新判断。下单前用新报价核验入场区、费用和剩余净优势。同币不重复持仓、同预测计划去重，平仓后冷却5分钟并要求新的计划。

## 退出与资金

持仓不超过60分钟，等待后按原一小时预测剩余时间缩短。计划内逆向波动不因一根小阴线退出；15分钟后仍无0.25初始风险推进且完整K线及当前价都偏离入场超过半个初始止损距离，可提前退出。真实保护价/目标触发优先；利润达到成本1.5倍与价格风险0.5倍中的较大者后，保护到含费保本。绝不因亏损放宽保护或自动翻向。

费用取用户配置与12基点（0.12%往返）较大者，为估计不是已核实费率。历史路径统计扣除此成本，但未来滑点和费用仍可改变收益，不能承诺本金无损。

不设固定持仓笔数上限。当前历史路径PAPER每笔最多4%权益、组合最多12%，不再把预算预先除以尚未出现信号的币，也不再因相关敞口把单笔仓位折半；所有新单统一受12%组合计划止损上限约束。信号成立后以真实市场TP2扣除估计往返费用后的单位收益倒算所需名义仓位，并直接放大到TP2计划净利润至少30U；30U不是额外拒单条件、利润目标或上限，不会缩短或拉远真实TP2，市场空间更大时利润继续更大。该模拟仓位可使用流动性、波动、强平缓冲与50倍硬上限共同允许的杠杆空间；单笔计划止损仍不突破4%。按可用保证金定仓，预留权益5%缓冲。

三连净亏暂停新单30分钟。UTC日初权益12%的已实现加完整估计退出成本的浮亏触发持久当日暂停，次日北京时间08:00解除再判断。已有持仓继续按开仓时不可变计划管理，不因新仓位规则追改。
