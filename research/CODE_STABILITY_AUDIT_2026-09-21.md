| 止损价格精度 | 带小数尾数的科学计数法价格步长计算错误，可能生成不在交易所价格网格上的止损 | 修正小数位计算；多种步长、多空与边界价格回归；原有向外取整方向不变 |

| 注册重试鉴权 | 注册请求编号被当作替代登录凭据，同一编号和用户名在错误密码下仍可取得会话；任意无效邀请码也可消耗密码推导工作 | 重试也验证原账户密码；无效邀请在昂贵密码推导前拒绝，最终原子校验保留；正常幂等重试继续成功 |
| 会员删除索引 | 删除旧账户的后续步骤可能删掉已被新同名账户占用的登录索引 | 仅删除仍归属于旧账户的引用；并发重用用户名回归 |
| 删除失败恢复 | 执行账户已删除、目录步骤失败后，重试被永久 410 阻挡 | 删除标记保持普通访问拒绝，仅允许绑定内已验证所有者的清理重试确认；覆盖重启 |
| 删除原子性 | 清空执行账户与写入删除标记之间中断，可能留下可重新初始化的空账户；旧异步请求或统计任务可能写回已删除数据 | 原子清理数据、写入删除标记并删除 alarm；覆盖分批清理、失败回滚、重试、延迟请求正文、结算与成交额写入 |
| 会员控制并发 | 较早的开启请求在等待权限回复期间，可能覆盖稍后的强制停止或凭据变更 | 控制代次检查；较早请求不得越过新的停止/凭据意图，现有持仓保护不变 |
| 行情 HTTP 连接 | 错误响应未释放响应体便尝试备用地址，可能占用可复用连接 | 先取消错误响应体再重试/抛错；不修改超时值、请求频率或数据有效期 |
| 冷启动扫描恢复 | 重启后目录加载失败但行情请求成功时，以空目录过滤并清空原扫描池，误记成功；空目录响应也能覆盖有效缓存 | 目录为空或上游目录结果为空时，在修改状态前抛错，交原有失败重试；实际构造器与可选任务回归保留扫描池，合法低波动零结果仍按原策略成功 |
| 净值加载 | 收到响应头后提前清除超时，响应体卡住会让所有后续加载一直等待 | 超时与取消覆盖整个响应体读取；失败保留历史，后续可以继续 |
| 界面账号隔离 | 旧账号/旧页面的迟到操作回复可能覆盖新账号显示，迟到 401 可能退出新会话 | 按账号隔离组件并校验操作代次；执行实际 TSX 回调的延迟成功/失败回归 |
| 长期曲线 | 对大量缓存点使用函数参数展开，可能触发浏览器堆栈溢出 | 迭代计算极值；160,000 点实际组件渲染回归 |
| 运行依赖 | 已安装 RSC 19.2.6 存在服务器函数拒绝服务公告，框架会选择显式安装的包 | React、React DOM、RSC 同步补丁升级至 19.2.8；核对实际构建采用补丁实现，见依赖审计 |
