# UI and historical settlement release

Scope: concise operational text, member terminology, separate current positions/recent10/older50 with10per archive page. Current positions are never capped. The underlying full immutable accounts/learning/order mapping/fill dedupe remain unchanged; view windows do not affect cumulative returns or trading frequency.

LIVE history uses a new private /api/live/history endpoint. It loads up to60 existing immutable closes and enriches only its read projection. One lazy optional Gate position_close GET page per minute, only while an authenticated user browses history. No extra trading alarm, order, leverage call or owner switch. The same inherited reader runs in isolated member storage. Gate signing/execution method bodies remain untouched; only an additional read method is present.

Native pnl is authoritative and not charged twice. pnl_pnl/pnl_fee/pnl_fund are optional breakdowns. Percentage uses this closed record's positive margin, not an exchange-calculated return promise. Actual zero is zero; missing or ambiguous is pending. Matching requires contract/side, first-open within original source reservation and first-observed fill, full matching size, entry price, and closing tag or unique timing, while rejecting overlapping source cycles. This intentionally leaves manually enlarged/partially reduced or historically ambiguous cycles pending rather than misassigning aggregate PnL. A cache is account/API-hash scoped, atomic before display and never overwrites immutable trading records. Corrupt caches, read failures, quota reserve and credential changes fail without execution side effects.

Record presentation is recent10 plus the next50, not destruction of necessary financial evidence. Archive pages are stable descending-time/id views. Version-rollout explanations are removed from the default operational UI; actionable errors, signal state, fee assumptions, permission/capacity limitations and new-only LIVE rules remain. Low-level reasoning and parity/settlement details are expandable.
