# 异动、10小时位置与双向计划

设计日期：2026-10-03 21:00，北京时间。
数据分配修订：2026-10-03 21:16，北京时间，按用户最新要求集中于外部异动发现与异动币K线。
状态：实现与本地机制验证完成，正在按原发布流程验收上线。本文件不是盈利验证。此前取消的 LYN 反向候选仍然取消，不能作为本方案的发布基础。

目标：先识别活跃币相对市场的异常变化，再观察自身约10小时位置、内部波段和本次移动方向。交易分为边缘突破、边缘回归、内部顺势。每笔订单在进场前固定成立、持有、失效、退出和反向条件。

## 1. 不变的执行约束

- 保留账户、历史、原有持仓的策略版本和手动 LIVE 意图；部署与模拟重置均不能重置市场观察。
- 沿用固定1000分配基准、现行风险/保证金/合约数量/杠杆规则，不新增缩仓或杠杆方案。止损距离影响原风险定仓计算，不能承诺每笔名义价值相同。
- PAPER 与 LIVE 消费同一逻辑计划，保留各自真实或模拟确认的成交价、部分成交和手续费。模拟不能把信号价当成交价，也不能承诺两个账户完全同价。
- 保留深度K线观察最多30、1分钟确认11席、现有2秒执行时钟及数据/存储预算；30不是外部轻量全市场发现的币数上限。研究不能阻塞持仓保护和财务写入。
- 不复用被取消候选的实际反向控制器。后续实现从最新已审核的 main 独立开始。

## 2. 数据和首次观察

研究层收缩为异动发现、重点币价格观察、计划证据和交易复盘。新策略不再进行独立宏观预测、长期市场叙事或普通币的全套深度研究；已有持仓仍保留其原规则需要的输入。

数据路径固定：Gate合约目录 → 真实外部共同币池 → 外部批量行情轻量发现 → 异动币历史K线/持续观察 → 已确认候选与持仓的 Gate 执行盘口。普通币只占轻量价格/活动数据，详细K线重心放在异常事件和实际持仓。

### 2.1 共同币池

- Gate只在启动/现有低频目录刷新中提供可交易USDT永续及合约数量、杠杆等元数据，复用缓存。目录读取与实时全市场tickers拆开，不再为了排名同时拉Gate全量行情。
- 核对外部交易所实际合约列表、交易状态、USDT永续类型与单位，不靠拼出BTCUSDT这样的字符串就声称有该合约。分页目录必须读全，不把第一页当全集；目录刷新复用既有后台调度且核算预算。
- 共同币池指Gate可交易且至少一个外部源真实支持同一资产的USDT永续；优先分配两个可用外部源以交叉核对，不要求五家同时上市。候选页/快照明确来源数；只有一家不伪称多源，执行资格仍须满足既有数据/风险合同。
- 新策略不对只有Gate上市的币做新入场研究，已经持有的Gate-only订单照原保护管理。当前来源短暂失联不是合约下架；缓存目录、实时健康与退市状态分开。
- 删除新发现路径中的Gate每15秒全量行情轮询；不把外部源失败自动转成Gate全市场扫描或Gate研究K线回退。Gate保留目录和真实执行/账户/保护所需请求。

### 2.2 全币池轻量发现

利用外部批量tickers在现有刷新周期内覆盖整个共同币池，不逐币发REST价格请求。用有时间戳的同源连续价格快照构造短时移动/加速度，与市场同周期中位移动比较。原始价格序列按币/来源有界保存，不生成伪OHLC，不把行情时间重复更新当成新价格证据。

外部ticker的24小时成交额只作粗活动筛选，不能以两次滚动24小时总量相减冒充精确15分钟成交额；候选的近期成交活动要从真实K线成交额核实。跨交易所也不把张数、基础币数量直接当作USDT成交额。

市场参考只需共同币池的轻量收益/涨跌广度，无需为了计算市场总体运动给每个普通币加载10小时K线。冷启动的短时价格基线覆盖、观察缺口和首次检测时间均公开；无法追溯的早期异动不回填成在线提前发现。

全市场轻量发现数量、排除数量、来源和实际更新时间独立统计。若共同币池超过原有缓存上限，必须先调整有界内存实现并通过资源检查，不能静默截断后仍叫全币池发现。发现层不受30个深度观察席的限制。

### 2.3 重点币K线分配

检测到异常后，从实际支持该币的健康外部源加载约10小时完整5分钟线，并优先分配后续1分钟确认。数据源按币固定主/备，不对每个币同时向所有交易所重复拉历史。

深度观察最多30币，1分钟确认11席；已有持仓/待执行保护优先，同时保留新异动的确认席，不用普通币探索填满名额。候选超过容量时按异常程度、发现时间、活跃度和计划状态排序，保留轻量事件与明确的排队/未加载原因；不能把未加载误写成没有异动。除持仓与待执行计划外，未异常的币不持续占详细K线刷新额度。

异动币首载为真实历史回补，不必等在线运行10小时。之后按已完成K线更新，支持增量的源补新线；不支持可靠增量的源允许有界覆盖刷新，不能谎称接口已有增量能力。旧事件/订单的冻结窗口不被缓存淘汰，普通无持仓事件结束后释放深度席，继续保留轻量发现。

正常详细输入为选中币5分钟线最多120根、重点币1分钟线最多90根，以及近期美元成交额与 Gate 实际执行盘口。全市场发现不等于每个币同时拥有这两份完整历史。

异动研究比较同一时刻、同一周期的自身移动、市场中位移动和该币正常波动。不响应但活跃的币仍可观察；只有自身出现方向移动才可产生交易计划。相对强弱不能替代实际上涨/下跌方向。市场比较只负责发现和排序，不作为统一多空许可。

第一版复用现有特殊币分类、相对残差/自身加速和近期活动检测，不新增一套叠加指标。当前活动检测的2500U/15分钟与相对活动比只是已有最低活动条件，不代表订单一定能成交；真实盘口和原生下单约束继续负责执行。

新入场所需方向/位置证明已经成立，或已有实际仓位需要保护时，才为该币分配Gate执行行情；有外部异常但尚无可执行计划的币不长期占Gate实时席。不能把其他交易所的盘口拿来模拟Gate的真实成交/止损。Gate请求压力减少不等于零请求，也不消除外部与Gate之间的价格基差和执行延迟。

每次扫描保留指标值、比较周期、市场样本数量和原因。仅有涨跌排行榜排名不构成确认。成交额未知标为未知，不能推算成活跃。未移动的活跃非响应币留在观察中，不因为评分高直接交易。

5分钟/1分钟必须来自同一可追踪的价格源。来源切换不能把两个价格尺度拼成突破；原计划保持原来源与边界，无法取得原来源时停止该计划的新确认，其他币照常运行。已经持仓继续由有效的 Gate 保护管理。

## 3. 固定约10小时位置

在首次在线发现异动时，固定参考截止时间：触发异动所属5分钟K线的起始时刻。范围仅使用此前已经完成的K线，本次异动不得抬高上沿或压低下沿。

目标窗口为120根连续完整5分钟K线。现有120根缓存剔除触发线后可能只有119根：119根可作为明确标注的9小时55分钟近完整窗口；低于119根或存在缺口只观察，不伪称完整10小时。实现可在同源现有刷新时保留一根额外旧线解决这个边界问题，不增加请求或周期。新增源冷启动不靠合成K线补足历史。

- 上沿 H = 窗口最高 high；下沿 L = 最低 low；宽度 W = H-L；包括影线。
- 保存极值时间、来源、实际覆盖分钟、已完成线数量和窗口摘要。
- 同一事件和其订单始终使用同一 H/L。持仓超过10小时也不能用新滚动区间追溯否定它。
- 新异动事件可计算新窗口，但不得覆盖旧持仓计划。行情持续变强不是重置同一个事件的理由。
- H/L 只是位置范围，不自动宣称这里是震荡区间、一定存在支撑压力、一定可以走到另一端。

只在新完成5分钟线到来时计算波段；每次行情循环只更新当前价格位置，不重复遍历完整窗口。

## 4. 正常波动、边缘和内部方向

以下均为待运行检验的第一版默认参数，不是历史优化结果；参数集中版本化。

N5 为异动前最近20根完整5分钟线真实振幅的中位数；N1 为确认开始前最近20根完整1分钟线对应值。至少2个最小价格单位作为数值下限。异常线不能反过来扩大它自己的确认容差。

边缘距离 E = min(0.75*N5, 0.10*W)，外/内侧确认缓冲 D = max(2个价格单位, 0.20*N5)。若 E 不大于 D，则这份范围没有可用的边缘确认带，不能强行开边缘单。边缘范围为 H±E 与 L±E。初次事件固定 N5/E/D；持仓的波段噪声可随后来已完成数据更新，但原区间和已记下的失效位不放宽。

内部方向使用完成5分钟线形成的摆动：价格相对候选极值反向移动至少1.5*N5时确认一个波段拐点，记录极值发生时间及后来实际确认时间，不能把后者回填到极值当时。保留最近三组同类拐点。

- 最近三个有效低点依次抬高，每次差异超过0.5*N5，且高点没有同时持续降低：偏多。
- 最近三个有效高点依次降低，每次差异超过0.5*N5，且低点没有同时持续抬高：偏空。
- 高点下降且低点上升：收缩，不能强选多空；样本不足或混乱：不明确。
- 最近有效波段确认已超过2小时：方向过时，内部顺势不使用它；边缘处仍可产生新的突破/回归确认。

内部方向是优先选择，不是边缘新证据的绝对否决。真实向下突破成立时，旧偏多结构应转为失效说明，而不是阻止做空。

## 5. 三类交易分开

| 位置与本次行为 | 计划 | 不能做的事 |
|---|---|---|
| 上沿向外上涨/下沿向外下跌 | 边缘突破，确认后向外参与 | 未收完5分钟线提前追；把本次新极值算进区间 |
| 接近、到达或越过上沿后退回/下沿后反弹 | 边缘回归，确认后向内参与 | 仅因接近边缘就逆向；退到深处再追回归 |
| 区间内部，移动与有效内部方向一致 | 内部顺势 | 在即将撞到前方阻挡的位置无条件追单 |
| 区间内部，移动与内部方向相反或方向不明确 | 观察新的波段是否成立 | 原单止损后机械翻仓；用相对强弱代替实际方向 |

内部顺势入口要求完成5分钟线已出现同向推进，并由随后完整1分钟线确认，而不是单纯存在几个历史抬高低点。首个计划失效位为最新已经确认的内部支撑/压力；执行时检查到最近前方波段阻挡或外边缘的成本后空间。空间不足就保留观察，不能编造1.5%目标使其通过。

## 6. 突破与1分钟确认

向上突破：完整5分钟线收盘 > H+D。向下对称。只刺穿的影线不够。

突破初始硬保护位：多单取确认5分钟线低点与 H-E-D 中更低的一个，空单对称取高点与 L+E+D 中更高的一个。边缘内少量回踩留给完成线确认，不能把 H-D 直接当成所有突破单的硬止损；实际风险仍由原生预算检查。

随后只使用该5分钟线收完后新开始并收完的1分钟线，不重复使用其内部小线。两根连续强势同向线即可确认；若夹着一根小停顿，可在三根中由两根强势同向线确认，停顿不能退回边界内。出现实质反向线则本次小线确认重新观察，不使用旧线拼凑。

强势线默认：实体占本根振幅至少55%、实体不小于确认前20根实体中位数、收盘位于方向端25%内。确认序列收盘同向净推进至少 max(N1,0.25*N5)，不是两根颜色相同但价格没有前进的线。三根中的停顿不要求创新高/低；两根强势线必须真正推进。

每个证明绑定事件、原边界、策略版本、各K线时间及最迟有效时间。完成证明距实际准备开仓不得超过2分钟；执行价格已偏离证明价超过一个 N5 时判为错过，不能降低条件追入。原生风险、保证金、实际盘口和成交成本检查仍需要通过。

分析来源与 Gate 存在价格基差时，按同一批有时间戳的价格计算基差并记录。没有可靠的尺度映射时不比较 Gate 价与外部裸边界。两端不同时间的价差不能冒充突破或回归。

## 7. 边缘回归确认

接近、到达、超过原极值都可纳入，边界数字是否被穿过不是必要条件。须记录本次确实从内侧到达边缘、形成尝试极值，然后向内退回。

上沿回归默认确认：一次完整5分钟线收在 H-D 内侧；随后2～3根完整1分钟线按同一强势规则向内推进，不能已经重新站回 H+D 外侧。下沿对称。回归入口必须仍处于对应边缘范围。参考止损为本次尝试极值外加缓冲；不得镜像套用上一笔数量或止损。

若此前根本没有向外突破，仍可按本次接近后退回的过程开边缘回归；若此前已持有突破单，则它是预先准备的失败分支。价格已经直接跌/涨到区间深处时，原单退出照常，反向入口取消。不能把价格已走过的空间当成剩余机会。

回归的第一观察位置为最近的实际内部波段阻挡；无清楚阻挡时用区间中心作几何观察位置，并明确不是预测目标。到达后不自动全平：停止推进或出现反向结构才退出，继续推进则更新已确认的波段保护。不会为了抓大利润假设必然穿越整个区间。

## 8. 持有、普通回调与计划失效

尚未入场而1分钟不强势：等待，不提前开仓。已经入场：一两根回头K线只记录，不直接退出；异动评分降低、市场方向变化、币掉出扫描排名也不单独结束持仓。

连续回头定义为至少两根完成1分钟线反向、累计移动超过 N1，并损伤当前推进，而非纯数红绿柱。它触发复查，不等同硬止损或反向许可。

边缘突破持有分支：
1. 回踩仍守在原边缘/外侧，未破有效持仓波段：持有。
2. 已重新进入区间但尚未有完整5分钟回内确认：复查；现有硬止损始终有效。
3. 完整5分钟收回内侧后，新的1分钟反攻无法收复外侧并转向内部：突破计划失效，立即提交退出；边缘与回归确认同时成立才提交依赖退出确认的反向计划。
4. 收回内部后一整根后续5分钟线仍无法重新收复外侧，但只横着走、没有向内强势证明：退出原突破单，不自动反向。

内部顺势持有分支：最新完成5分钟波段支撑/压力仍有效时持有；有效波段被超过正常缓冲的完成K线破坏，或硬止损触发时退出。1分钟微小回调不替代5分钟持仓结构。退出不产生反向许可。后来到边缘须建立新的边缘计划及证明。

硬止损由新计划实际方向及结构计算，经原生预算定仓，实际成交后校验。止损不放宽；执行层有新鲜可执行价格时不等待5分钟收盘。价格跳空与执行滑点可能使真实损失超过计划值，记录事实，不宣称数学上绝对封顶。

## 9. 盈利保护与无进展

交易不按持有5分钟、10分钟自动结束。入场失效依据和持仓更新依据分开。

保护优先使用后来已确认的5分钟波段。多单只抬高保护、空单只降低保护；不因研究或数据重启回退保护。

为避免大利润完全吐回，第一版增加有盈利门槛的保护底线。R 为最初计划的价格风险距离，后续不重置。有效净浮盈峰值至少由三次不同真实行情更新保留，不能把一个瞬间异常报价当成峰值。

| 已保留峰值相对初始风险 | 保护底线的初始设计 |
|---|---|
| 低于2R或尚未覆盖退出成本 | 原结构保护，不机械锁小利润 |
| 达到2R | 尝试保留峰值净利润的50% |
| 达到4R | 尝试保留65% |
| 达到6R | 尝试保留80% |

底线不得贴到峰值一个正常5分钟波动以内；不满足时使用较宽的噪声容差，实际可保护比例如实显示，不声称已经锁住80%。结构保护与盈利底线选择实际更有保护作用的一条，均不得放宽已提交的止损。实际可执行退出价触及已生效保护时退出；这不是反向证明。

每15分钟复查进展。持续30分钟没有同向新进展，且净优势已退到成本/噪声附近时，进入无进展复查；只有随后有完成结构损伤或明确恢复失败才退出。时间本身不杀掉慢启动订单，有明显价格优势的订单也不因横盘自动结束。

## 10. 边缘反向的执行顺序

平仓条件、反向信号条件和反向执行条件是三个独立字段。已确认做反且满足边缘分支时马上提交关闭，不重新用评分推翻原计划。

每个账户执行顺序为：关闭原方向 → 确認原方向剩余数量为零 → 用新的实际价格再次检查边缘/证明有效性/成本/风险 → 开反方向。部分平仓、未知提交、残余数量不能当作完成；PAPER 和 LIVE 各自遵守确认依赖，不用一个账户的成交冒充另一个账户的事实。

原单平完时价格已离开边缘，则取消反向，而非追单。同一币有待执行动作时不能另开一个重复动作。第一次反向后的另一轮切换必须有在该反向成交之后新形成的完整5分钟证明和后续1分钟证明，不能反复消费同一组K线。内外缓冲区防止在一条线两侧的小抖动反复翻仓；不另加全市场暂停或机械冷却时间。

边缘判断不仅在信号时成立，在最终开仓时也必须成立。内部订单止损、盈利保护退出、无进展退出，均不得设置自动反向标志。

## 11. 候选和计划生命周期

未成交计划持续30分钟仍无有效入场证明时结束本次计划，保留结果；币仍可观察，新的异常变化可以建立新的事件。30分钟不是持仓时限。

事件ID、方向、参考区间和各证明时间不会因评分变化被重置。新事件不能复用旧证明；旧持仓不被新事件挤掉。扫描轮换保留轻量计划，不能把离开扫描当成失败。无法观察的时段注明缺口，不续算成连续确认。

已成交单以原版本管理到结束。后续参数变更只作用于新计划；不把旧成交悄悄改成新策略样本。模拟重置影响账户代次，市场事件继续保留；旧账户订单与新账户订单明确区分。

## 12. 快照、页面与预算

研究快照必须能回答选了谁、为什么选、当时在哪、为何入场、哪项计划失效、为什么平仓、有没有资格反向。

- 事件：检测/参考截止时间、自身与市场移动、活动值、来源、异常类型、是否晚发现。
- 位置：冻结 H/L、极值时间、实际覆盖、N5/E/D、内部高低点及实际确认时间、方向、当前相对位置。
- 计划：三类之一、实际方向、进场/守位/失效/退出/反向条件、初始风险、实际剩余空间和成本估计、参数版本。
- 证明：触发前后必要5分钟/1分钟K线、时间/来源；未收完/缺失/跨源不得标成完成证明。
- 执行：信号、提交、实际成交/平仓时间与价格、部分数量、延迟、证明过期/边缘失效取消、两账户的差异。
- 持有：有效结构、实际 MFE/MAE、净峰值、有效保护价与真实可保护比例、退出原因。
- 研究结果：所有被观察事件的15/30/45/60分钟结果，包括未成交和真实突破；缺失、容量遗漏单独记录。假想结果与真实账户盈亏分开。

每个实际成交计划必须保留一份用于计算范围/波段的不可变原窗口，不仅保存被选出的极值。连续窗口可用一个起始时间、5分钟间隔和最多120组原始OHLC编码；120*4个64位数是3840字节，Base64是5120字节，连同元数据/摘要限制在8KiB内。编码必须保留输入数值、来源和覆盖情况，不降精度，不把影线抹掉。最近活动检测、1分钟证明和触发后关键线另存紧凑证据。

原窗口附在现有不可变计划/交易证据写入中，一笔仅存一次，后续持仓/归档用引用，不每次刷新重复写入。它不装在可裁剪的24KiB热研究里，也不成为每个扫描币的长期全K线日志。后续快照可读取对应原窗口重算边界、噪声和内部方向；窗口缺失/无法读取须报告证据缺失，不能宣称这项判断已复盘。实现必须证明该载荷适配现有财务/归档大小及资源合同，否则修正存储实现后才可发布，不能通过省略关键证据使检查通过。

热研究保留现有24KiB级硬上限，按真实编码字节裁剪未成交旧事件的细节并计数。已成交计划/保护/财务身份和其原窗口证据不是可裁剪的可选研究。归档复用既有交易/保护写入，不新增定时写；不能为保存每次扫描反复写完整K线。具体最坏占用和付费资源必须在实现阶段通过原预算测试，不提前承诺额度保证。

执行页面每币只显示：异动方向；区间和当前位置；内部方向；当前执行阶段/下一触发条件。持仓补实际方向、浮盈亏和有效保护。顶部精简显示共同币池已扫描数量/时间、当前异动数、已加载K线数；排队和数据缺失明确区分。细节折叠，统一北京时间，不显示同一订单相互矛盾的多个策略标签。

实现容量说明：第一版使用 Bybit、OKX、KuCoin 的真实永续目录建立共同池；保留原五路行情健康检测，但没有合约目录证明的来源不参与新币池准入。最多30个深度K线席，24KiB热研究最多10份详细事件，最新发现另留8条展示样本；超过容量记录遗漏，不声称每个异常都已完整归档。实际成交的原始窗口保存在财务交易证据中，保护检查点只引用并校验不可变身份。

## 13. 实现与上线验收

纯模块分开：异动发现 → 冻结区间/波段 → 三类计划 → 持仓/退出/反向 → 原生执行适配；快照和页面读取同一份计划，不各自推导方向。只有一个新入场控制器有权下单。停止旧新单入口，不删除旧成交策略及财务记录。

后续按最新已审核 main 的干净工作区实现，不能混入此前取消的候选。必须完成如下机制验证：

1. 异动线/未来线不能抬高参考区间；滚动10小时和数据来源变化不修改已有边界。
2. 119根近完整明确标注；缺线不拼接、未收完线不确认；波段确认不回填。
3. 上下方向镜像；接近但没破极值也能确认回归；内部收缩不伪装成单边。
4. 突破5分钟线内部的小线不能作为其后的确认；弱推进、长影线和过期/追远分别阻止错误入场。
5. 正常小回调不出局；连续回头只复查；收回且未能收复时按计划退出。
6. 内部订单的止损/锁利/无进展退出不自动反向；边缘信号成立但最终成交位置深入内部时取消反向。
7. 部分平仓、未知提交、重启和重复事件不生成重复反向单；原方向未清零不能反向开仓。
8. 盈利保护只收紧、不后退；达到观察位置不机械全平；成本口径不重复扣费。
9. 旧持仓保留旧规则、账户/历史/LIVE意图不变；模拟重置不清除市场状态。
10. 资源压力先裁剪可选研究，不阻塞保护/下单；原窗口无损编码往返、8KiB上限、引用去重和归档读取成立；快照与页面能解释同一决策。
11. Gate新研究请求只剩低频目录，普通外部异常不占Gate执行席；外部故障不回退Gate全市场扫描。共同币池实际合约/状态/单位/分页准确；轻量发现遍历整个币池，深度30/分钟11分配不会冒充全市场只有30币；异动候选初次历史加载、排队和释放有明确证据。

这是功能与因果验证，不是历史盈利回放。上线后的自然订单分三类分别观察净收益、费用、持有周期、误判、反向位置与大赢家保留情况，再针对实际证据调整参数。不能承诺第一版一次确定最佳阈值或长期盈利。

## 14. 推演结论

| 场景 | 预先确定的动作 |
|---|---|
| 内部偏多，上沿5分钟只留长上影 | 不追突破；若边缘向内确认，再考虑回归 |
| 内部偏多，向上完整突破且小线强 | 做多；旧边界固定 |
| 突破后两根很小红线，仍守外侧 | 持有，不因颜色退出 |
| 突破后收回内侧，反攻失败，仍近边缘 | 平原单，成交清零后按新价格反向 |
| 同一失败过程已经跌到中部 | 平原单，取消边缘反向 |
| 内部多单跌破内部支撑 | 平多，不自动做空 |
| 内部多单到上沿才形成新回归 | 用新的边缘证明和计划判断，不能沿用旧退出信号 |
| 旧偏多但下沿真实突破成立 | 按新证据做空，记录旧结构失效 |
| 强突破已经走很远才看到 | 记录错过，不假造剩余空间追入 |
| 市场排名变差而自身持仓结构健康 | 保持原计划 |
| 回归到中心后仍持续强势向内 | 更新波段保护，不因到中心自动全平 |
| 数据暂缺/异动研究满/扫描轮换 | 原保护继续有效；缺失不制造反向信号 |
